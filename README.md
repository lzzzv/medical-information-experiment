# 保健中心生理量測系統（醫學資訊實驗期末報告）

大二下「醫學資訊實驗」課程的期末報告（2025/06）。Windows 視窗程式，透過序列埠連接六合一生醫電子整合平台（BMEP），量測並記錄使用者的生理數值。

## 主要功能

- 輸入姓名、科系、學號後開始量測（未填完整會跳出提醒）
- 量測血壓、血氧、心率、體溫，即時畫出血壓曲線、脈搏波形與三導程心電圖（I、II、V）
- 儲存量測結果，管理者登入後可查看所有人的歷史紀錄

## 使用技術

- C#、Windows Forms
- 序列埠（SerialPort）通訊：儀器以 RS232 轉 USB 連接（鮑率 115200）；開發時用課程提供的 BioSignal 模擬器經藍牙傳送，資料格式相同
- 封包解析：每個封包開頭為 FF，第二個位元組代表訊號種類（F4 血壓、F3 血氧與心率、E2 心電圖或體溫）
- GDI+（Bitmap、Graphics）即時繪圖
- FIR 濾波
- 量測紀錄以文字檔（data.txt）儲存

## 程式架構

```
醫資實驗期末報告/
├── 銘傳保健中心.cs   首頁：輸入資料、管理者登入
├── 偵測系統.cs       量測畫面：連接儀器、解析資料並畫出波形
└── 資料紀錄.cs       顯示與儲存量測紀錄
```

1. 首頁輸入使用者資料
2. 量測畫面透過序列埠讀取儀器資料，解析後顯示數值與波形
3. 按下儲存後寫入紀錄檔，可在資料紀錄頁查看

## 執行方式

使用 Visual Studio 開啟 `醫資實驗期末報告.sln` 執行。需連接六合一生醫電子整合平台，或以 BioSignal 模擬器經藍牙測試，並在量測畫面選擇對應的連接埠。
